## 4. How to Run the Tests

### Method 1: Using Standalone Runner (`e2e_tests/run_e2e.py`) — Recommended
```bash
# Run full suite in-process (development baseline)
python e2e_tests/run_e2e.py

# Run against live backend server (e.g. Rust backend on port 8001 or Bun on port 8000)
python e2e_tests/run_e2e.py --url http://127.0.0.1:8000

# Run specific tier
python e2e_tests/run_e2e.py --tier 1
python e2e_tests/run_e2e.py --tier 2
python e2e_tests/run_e2e.py --tier 3
python e2e_tests/run_e2e.py --tier 4

# Run specific domain filter
python e2e_tests/run_e2e.py --domain prediction
python e2e_tests/run_e2e.py --domain hospital

# Export machine-readable JSON report
python e2e_tests/run_e2e.py --json-report test_results.json
```

### Method 2: Using Pytest
```bash
# Run full suite with pytest
python -m pytest e2e_tests/ --no-cov -q

# Run with parallel execution
python -m pytest e2e_tests/ -n auto --no-cov -v

# Run against live server with pytest
E2E_API_URL="http://127.0.0.1:8000" python -m pytest e2e_tests/ --no-cov -v
```
